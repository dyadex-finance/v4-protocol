# Dyadex Finance V4 Protocol

Local Foundry workspace for Uniswap v4-core and v4-periphery development.

## Requirements

- Foundry (forge, cast, anvil)
- Git

Install Foundry:

```bash
curl -L https://foundry.paradigm.xyz | bash
foundryup
```

## Install dependencies

From the repository root:

```bash
forge install
```

## Common commands

Build:

```bash
forge build
```

Test:

```bash
forge test
```

Format:

```bash
forge fmt
```
